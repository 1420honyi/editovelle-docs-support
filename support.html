聯絡 Editovelle Docs

可透過 GitHub 支援頁提出問題或隱私請求。留言是公開的；請只描述問題，不要附上文件、簽名、身分資料、付款收據或禮包碼。

開啟支援頁

閱讀無需登入；建立留言需要 GitHub 帳戶。

如何找到另存的新檔？

使用「另存新檔」，在系統選擇器指定資料夾和檔名。若儲存在雲端檔案供應者，請到您選擇的服務尋找；App 私人草稿和外部另存副本是不同資料。

如何簽名、縮放與旋轉？

開啟 PDF，點右下筆形按鈕，再選簽名或標註。放入簽名後，使用物件的控制點或雙指調整大小、位置與方向；完成後另存副本。

文件顯示與電腦不同？

支援格式與編輯能力依平台、版本而異。複雜排版或專用字型可能影響顯示；請保留原檔，並在傳送前檢查輸出。回報時提供格式與現象即可，不需上傳原文件。

去廣告、恢復購買與取消訂閱

訂閱只移除廣告，文書工具不需訂閱。商品與服務尚未啟用時，App 會顯示暫不可購買。已啟用的版本可在訂閱畫面恢復購買；取消續訂請至 Apple 訂閱管理或 Google Play 訂閱管理。刪除 App 不會自動取消訂閱。購買價格與續訂條件以商店確認畫面為準。

Contact Editovelle Docs

Use our GitHub support page for technical questions or privacy requests. Issues are public. Describe the problem without attaching documents, signatures, identity details, payment receipts, or gift codes.

Open support

Reading does not require login. Posting requires a GitHub account.

Where is my saved copy?

Use Save As and choose a folder and filename in the system picker. If you chose a cloud file provider, find the copy in that service. Private app drafts and exported copies are separate.

How do I sign, resize, or rotate?

Open a PDF, tap the pen button, and choose a signature or markup tool. Use the placed signature's handles or two fingers to adjust its size, position, and rotation. Save a separate copy when finished.

Why does a document look different?

Supported formats and editing features vary by platform and version. Complex layouts and specialized fonts may affect results. Keep the original and check the exported copy before sending it. Report the file type and symptoms without uploading the document.

Ad-free access, restoration, and cancellation

Subscriptions remove ads only; document tools do not require a subscription. The app shows purchases as unavailable when products or services are not enabled. Enabled versions offer Restore Purchases in the subscription screen. Cancel renewals through Apple or Google Play. Removing the app does not cancel a subscription. The store confirmation screen governs price and renewal terms.
